# ESP32-S3 FPV Camera

FPV-платформа на ESP32-S3 с камерой OV2640 и 2× MG90S.

## 📁 Структура

- [Vision (MIT)](vision/) — открытая часть
- Database — закрытая часть (в приватном репо)

## 🚀 Быстрый старт

1. Прошей firmware из `vision/`
2. Подключись к Wi-Fi `ESP32-FPV` / `12345678`
3. Открой `http://192.168.4.1`
