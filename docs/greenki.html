📹 FPV-зрение для роботов и коплексов

Программный продукт на базе ESP32-S3 CAM + Wi-Fi: прямая трансляция, управление камерой и интеграция с базой данных. Работает в браузере, без сторонних приложений.

Часть нашего проекта "FPV-зрение" — это «глаза» комплекса роботов по сортировке и переработке пластикового материала. Камера даёт оператору возможность наблюдать за процессом ИЗВНЕ, в режиме реального времени.

⚠️

Проблема

  • Роботизированным комплексам нужны «глаза» — но IP-камеры дорогие, сложные и "НЕ НАШИ"
  • Оператор не видит процесс изнутри — сортировку, нагрев, экструзию и прочее
  • Готовые решения требуют сторонних приложений и драйверов
  • Нужно дёшево, просто, без "кривого" перевода и без установки — прямо в браузере
💡

Решение

Программный продукт FPV-зрения на базе платы ESP32-S3 + OV5640 + веб-интерфейс + WIFI. Работает в любом браузере, без приложений.

  • 📹 Прямая трансляция с камеры ESP32-S3 по Wi-Fi
  • 🔍 Цифровой зум — 1x / 1.5x / 2x / 3x
  • 🔄 Поворот изображения — 0° / 90° / 180° / 270°
  • 🪞 Зеркало H/V — для удобства оператора
  • 🎛️ Управление серво — поворот башни камеры
  • 🗄️ Интеграция с БД — данные и видео в одном интерфейсе
  • 🌐 mDNS-доступ — greenloop.local
  • 📡 AP + STA одновременно — работает в двух сетях
⚙️

Как это работает

1

Камера

ESP32-S3 снимает и передаёт видео по Wi-Fi

2

Сеть

mDNS greenloop.local или точка доступа

3

UI

Веб-интерфейс с зумом, поворотом, зеркалом

4

Интеграция

Связка с базой данных и отчётами

🎯

Где применяется

FPV-зрение — универсальный модуль. Для фестиваля «Гринки» мы демонстрируем наш продукт в связи с комплексом роботов по сортировке и переработке пластика:

  • ♻️ Агрегат-сортировщик — контроль по цвету и размеру
  • 🔥 Мини-фабрика филамента — контроль нагрева и экструзии
  • 🖨️ 3D-печать — наблюдение за процессом печати
  • 🏭 Большой комплекс — единая система зрения для всех узлов

FPV-зрение — это не «камера для одного робота», а модульное решение, которое можно масштабировать на любой производственный агрегат.
