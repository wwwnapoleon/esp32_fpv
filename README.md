# ESP32-S3 FPV Camera + 2× MG90S Servo

## 📁 Структура проекта

Проект разделён на две части с разными лицензиями:

| Каталог | Что это | Лицензия | Доступ |
|---|---|---|---|
| [`vision/`](vision/) | Виртуальное зрение — FPV-камера, серво | 🟢 **MIT** | Открытый |
| `database/` | База данных Лицея №8 | 🔴 Проприетарная | 🔒 [Приватный репо](https://github.com/wwwnapoleon/esp32_fpv_database) |

- 🟢 **Vision** — можно свободно использовать, изменять, распространять.
- 🔴 **Database** — только для внутреннего использования в Лицее №8.

Подробности лицензий: [LICENSE](LICENSE), [LICENSE-OPEN](LICENSE-OPEN),
[LICENSE-PROPRIETARY](LICENSE-PROPRIETARY).

FPV-платформа на базе **ESP32-S3-N16R8** с камерой **OV2640/OV3660**,
двумя сервоприводами **MG90S** (pan/tilt) и веб-интерфейсом для просмотра
видеопотока со смартфона прямо в браузере.

![demo](docs/images/screenshot.jpg)

## ✨ Возможности

- 📷 MJPEG-поток с камеры OV2640 (до 1600×1200, ~15–25 FPS)
- 🎮 Управление двумя MG90S (pan/tilt) из веб-интерфейса
- 📱 Адаптивный UI — работает на iPhone/Android в Safari/Chrome
- 🔌 Точка доступа Wi-Fi **или** подключение к домашней сети
- 🎛️ Плавное движение серво (шаговый режим, без рывков)
- 🧠 GPIO серво не конфликтуют с пинами камеры ESP32-S3
- 🐍 Весь код в одном `.ino` — легко прошить через Arduino IDE

## 🧰 Аппаратная часть

| Компонент | Кол-во | Примечание |
|---|---|---|
| ESP32-S3-N16R8 (DevKitC-1) | 1 | 16 МБ Flash, 8 МБ PSRAM |
| Камера OV2640 / OV3660 | 1 | Модуль FPC 24-pin |

| Понижающий DC-DC (5V ≥ 2A) | 1 | Для питания серво |

## 🔌 Подключение

### Камера (ESP32-S3 + OV2640)

| Камера | ESP32-S3 |
|---|---|
| SIOD | GPIO 4 |
| SIOC | GPIO 5 |
| VSYNC | GPIO 6 |
| HREF | GPIO 7 |
| XCLK | GPIO 15 |
| PCLK | GPIO 13 |
| D0–D7 | GPIO 11, 9, 8, 10, 12, 18, 17, 16 |
| PWDN | -1 (не используется) |
| RESET | -1 |

### Серво MG90S

| Серво | Signal | VCC | GND |
|---|---|---|---|
| Pan (гориз.) | GPIO 38 | +5V БП | общий GND |
| Tilt (верт.) | GPIO 39 | +5V БП | общий GND |

> ⚠️ **Серво НЕ питаются от ESP32!** Используйте отдельный БП 5V ≥ 2A.
> GND БП и GND ESP32 обязательно соединить.

Схема целиком — [`docs/WIRING.md`](docs/WIRING.md).

## 🚀 Быстрый старт

### 1. Arduino IDE

Установи:
- **ESP32 by Espressif** (Boards Manager) ≥ 3.0.0
- **ESP32Servo** (Library Manager)

Настройки платы:

```
Board:            ESP32S3 Dev Module
USB CDC On Boot:  Enabled
Flash Size:       16MB (128Mb)
PSRAM:            OPI PSRAM
Partition Scheme: 16M Flash (3MB APP/9.9MB FATFS)
Upload Speed:     921600
```

### 2. Прошивка

1. Открой `firmware/esp32s3-fpv-cam/esp32s3-fpv-cam.ino`
2. Выбери порт и нажми **Upload**
3. Открой **Serial Monitor** (115200) — увидишь IP-адрес

### 3. Просмотр со смартфона

- **Режим AP (по умолчанию):**
  - Подключись к Wi-Fi `ESP32-FPV` / пароль `12345678`
  - Открой в браузере: `http://192.168.4.1`

- **Режим STA:** задай `WIFI_SSID` и `WIFI_PASS` в прошивке.

Через браузер смартфона:
- Стрим открывается автоматически
- Слайдеры pan/tilt управляют серво
- Кнопки — пресеты (центр, лево, право, вверх, вниз)

## 📡 API

| Метод | Endpoint | Назначение |
|---|---|---|
| GET | `/` | HTML UI |
| GET | `/stream` | MJPEG поток |
| GET | `/capture` | Одиночный JPEG |
| GET | `/servo?pan=90&tilt=45` | Углы серво 0–180 |
| GET | `/status` | JSON: FPS, RSSI, углы |

Пример:
```bash
curl "http://192.168.4.1/servo?pan=120&tilt=30"
```

## 🧪 Тестирование

- Открыть `http://<ip>/stream` в VLC — поток должен играть
- Проверить `/status` — увидеть FPS и текущие углы
- Подвигать слайдеры — серво должны плавно поворачиваться

## ⚠️ Известные ограничения

- MJPEG поток потребляет ~2–4 Мбит/с, желательно Wi-Fi 5 ГГц на роутере
- При 1600×1200 возможны пропуски кадров — снизь до SVGA
- Питание серво от USB ESP32 **недопустимо** — будет brown-out и рестарт
